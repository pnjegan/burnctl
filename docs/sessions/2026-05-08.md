## NEW standing rules from this session

### Rule #21
In-process module imports are cached in sys.modules. Code changes 
do NOT take effect in long-running services until restart. 
Downstream caches (DB-stored snapshots, in-memory state, computed 
aggregates) may still reflect pre-fix data. Acceptance test = live 
production behavior, not function-isolation tests.

### Rule #22
When a fix touches a long-running service, inventory turn must 
include "what caches consume the data this fix produces?" — list 
every layer between code-on-disk and observable-behavior.

### Rule #23
End-to-end acceptance test = math verification when possible. INV2 
closed when 138973-132469=6504=3×2168 balanced exactly. Function-level 
"returns expected output" is not sufficient.

### Rule #24
Backlog items written from memory or partial state expire fast. 
Before scoping any "real bug" from a stale handoff, reproduce it 
from the live code or live data first. If you cannot reproduce in 
2 minutes, the item is a candidate for wontfix.

Today: 3 wontfixes confirmed (DASH-002, chat_title_sync Bug 2, 
DASH-001). Pattern: 3 of 6 investigated items were brief artifacts.
